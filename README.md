# NSL - Nmap Script Lookup Tool

## Requirements
- Python 3.x (recommended: 3.8+)
- Internet connection (for installing dependencies)

## Installation
1. Open a terminal in this folder.
2. Install dependencies:
   pip install -r requirements.txt

## Usage
Run the tool:
   python NSL_0.py

## Special Note for Windows Users
if any issues were faced during the installation process phase regarding the libraries you will need to manually install the library "pryeadline3"
install it manually :
    pip install pyreadline3
